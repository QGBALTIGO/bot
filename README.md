# Source Baltigo

Bot e plataforma Source/Baltigo.

## Catálogo de personagens

A limpeza ampla do catálogo está sendo preparada na branch `catalog-cleanup-v1` / PR #40.

- O catálogo de produção permanece inalterado até a revisão final.
- Aposentadorias de personagens não são aplicadas automaticamente por CI.
- Antes de qualquer aplicação, a lista passa por uma trava baseada no uso real da coleção.
- Quando uma carta for aposentada, a migração prevista compensa **1 Coin por cópia removida** da coleção do usuário.
- AniList é usado na auditoria para identidade, papel e sinais de popularidade; imagens do AniList são apenas referência temporária e não a fonte final de arte.

> A documentação detalhada e os scripts de auditoria/migração estão no PR de limpeza; este aviso existe para deixar explícito que nenhum artefato de auditoria deve ser tratado como migração de produção por acidente.
