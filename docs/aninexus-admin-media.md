# Painel AniNexus de mídia 2:3

A branch inclui a evolução do pipeline de mídia iniciada antes dos hotfixes da MiniApp.

O objetivo é permitir gestão administrativa das imagens dos personagens sem alterar o `character_id` canônico usado pela coleção, Dado, ranking, trocas e demais sistemas do Source.

O frontend expõe uma área administrativa dedicada; o backend mantém metadados de mídia separados da identidade do personagem e valida permissões administrativas antes de aceitar alterações.
