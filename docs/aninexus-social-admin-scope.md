# Escopo social/admin AniNexus

Além dos hotfixes de produção, esta evolução mantém o trabalho já iniciado em social/admin: dados de perfil social passam a vir de fontes reais quando disponíveis, e a área administrativa recebe o fluxo de gestão de mídia dos personagens.

Recursos ainda não suportados não devem exibir dados fictícios. A regra desta fase é preservar IDs e tabelas canônicas do Source, adicionar estado novo apenas quando necessário e manter gravações sensíveis protegidas por autenticação e transações.
